Migrasi data: Firebase → Supabase

Halaman ini hanya untuk dipakai sekali, secara lokal (buka file ini langsung dari komputer, atau jalankan sebentar lewat python -m http.server) oleh Anda sendiri. Jangan di-upload ke hosting publik, dan jangan kirim Service Role Key ke siapa pun — key itu diketik di sini hanya untuk sesi ini, tidak disimpan di mana pun, dan memberi akses penuh ke database Supabase (melewati semua aturan keamanan). Setelah migrasi selesai dan Anda sudah memastikan datanya benar, hapus file migrate-to-supabase.html ini dari repo.
