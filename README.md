# Jadwal Training Zahir

Aplikasi pencatatan jadwal training Zahir ke client. Satu file, tanpa build: buka `index.html` di browser.

Data yang dicatat: nama perusahaan, trainer, tanggal, jam, versi Zahir, lama training, alamat perusahaan, kontak person client (nama dan telepon), dan biaya transport.

Saat dibuka langsung dari file atau hosting statis, data disimpan di localStorage browser yang dipakai.
